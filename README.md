Программа для шифрования и дешифровки текста с использованием ключевого слова и значения предыдущей буквы исходного текста.
Описание
PCW-1 Cipher — учебная реализация алгоритма шифрования текста.
Алгоритм использует:
английский алфавит A-Z;
ключевое слово;
позицию текущей буквы;
значение предыдущей буквы исходного текста.
Каждая буква текста преобразуется в числовое значение от 0 до 25.
A = 0
B = 1
C = 2
...
Z = 25
Принцип шифрования
Для первой буквы используется формула:
C₀ = (P₀ + K₀) mod 26
Для всех последующих букв:
Cᵢ = (Pᵢ + Kᵢ + Pᵢ₋₁) mod 26
где:
Pᵢ — позиция текущей буквы исходного текста;
Pᵢ₋₁ — позиция предыдущей буквы исходного текста;
Kᵢ — позиция соответствующей буквы ключа;
Cᵢ — позиция зашифрованной буквы;
26 — количество букв английского алфавита.
Ключ
Если длина ключа меньше длины сообщения, ключ повторяется циклически.
Например:
Текст: HELLOWORLD
Ключ:  KEY
Ключ будет использоваться следующим образом:
Текст: H E L L O W O R L D
Ключ:  K E Y K E Y K E Y K
Первый символ
Для первого символа предыдущей буквы нет, поэтому она не используется.
Применяется только текущая буква и первая буква ключа:
C₀ = (P₀ + K₀) mod 26
Для всех следующих символов используется предыдущая буква исходного текста.
Дешифровка
Для первого символа используется:
P₀ = (C₀ - K₀) mod 26
Для последующих символов:
Pᵢ = (Cᵢ - Kᵢ - Pᵢ₋₁) mod 26
При дешифровке предыдущая восстановленная буква сохраняется и используется для вычисления следующей.
Таким образом, дешифровка выполняется слева направо.
Пример:
Рассмотрим текст:
ABC
и ключ:
KEY
Значения букв:
A = 0
B = 1
C = 2
K = 10
E = 4
Y = 24
Шифрование первой буквы
Для A предыдущей буквы нет:
C₀ = (0 + 10) mod 26
C₀ = 10
10 соответствует букве: K
Шифрование второй буквы Для B используется предыдущая буква A:
C₁ = (1 + 4 + 0) mod 26
C₁ = 5
5 соответствует:
F
Шифрование третьей буквы
Для C используется предыдущая буква B:
C₂ = (2 + 24 + 1) mod 26
C₂ = 27 mod 26
C₂ = 1
1 соответствует:
B
В результате:
Исходный текст: ABC
Ключ: KEY
Результат: KFB
Возможности программы
Программа позволяет: шифровать текст; дешифровать текст;
использовать ключевое слово любой длины;
автоматически повторять ключ при необходимости;
работать с английскими буквами A-Z.
Ограничения
Текущая версия программы работает только с английскими буквами:
ABCDEFGHIJKLMNOPQRSTUVWXYZ
Поэтому символы, которых нет в алфавите, например:
1 2 3
! ? .
Текст и ключ автоматически переводятся в верхний регистр.
Запуск
Для запуска необходим Python.
Сохраните программу в файл:
main.py
Затем выполните:
python main.py
После запуска появится меню:
=== PCW-1 CIPHER ===
1 - Encrypt
2 - Decrypt
Введите:
Choose: 1
Enter text: ABC
Enter key word: KEY
Результат:
Encrypted: KFB
Для дешифровки:
Choose: 2
Enter text: KFB
Enter key word: KEY
Результат:
Decrypted: ABC

Формулы алгоритма
Encryption
i = 0:
C₀ = (P₀ + K₀) mod 26
i > 0:
Cᵢ = (Pᵢ + Kᵢ + Pᵢ₋₁) mod 26
Decryption
i = 0:
P₀ = (C₀ - K₀) mod 26
i > 0:
Pᵢ = (Cᵢ - Kᵢ - Pᵢ₋₁) mod 26
